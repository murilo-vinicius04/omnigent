# Bug report: a video that won't play in the viewer

- `viewer.txt`: what the file viewer showed.
- `network.txt`: the requests the browser made while opening the video.
- `server.log`: the server's log lines for that chat, from earlier the same
  evening and from the attempts to open the video.

Chat ids, file names and folder names were anonymized. Log lines are otherwise
unchanged, except that the browser user-agent and request ids were removed.
